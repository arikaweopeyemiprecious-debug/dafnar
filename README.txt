DAFNA BUSINESS RADIO WEBSITE

CONTENTS
- index.html: main website
- listen.html: dedicated live radio player page
- style.css: responsive styling
- script.js: mobile navigation and footer year
- assets/dafna-logo.jpg: supplied station logo

HOW TO USE
1. Extract this ZIP folder.
2. Open index.html in a browser to preview.
3. Upload the contents of the dafna_business_radio folder to your hosting provider (for example, Vercel).
4. Keep the assets folder in the same location as the HTML files.

IMPORTANT: CASTER.FM PLAYER SETUP
The supplied channel ID is already inserted in listen.html:
a29844a0-dd3c-4b21-bae8-5e6666b53145

Caster.fm's current embeddable widget also requires a PUBLIC TOKEN.
1. Sign in to the Dafna Caster.fm account.
2. Open Public Pages > Embed Widgets.
3. Copy the public token.
4. In listen.html, replace PASTE_PUBLIC_TOKEN_HERE with the real public token.
5. Redeploy the website.

The public token was not included in the station details supplied, so the player is prepared but cannot stream until that token is added.
